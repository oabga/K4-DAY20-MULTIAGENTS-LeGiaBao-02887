---
name: implement-error-handling
description: Use this skill to manage errors effectively during task execution.
---
- Identify potential points of failure in the code and document them.
- Use try-except blocks to catch exceptions and handle them appropriately.
- Log error messages with sufficient detail to diagnose issues later.
- Provide fallback mechanisms or default values where applicable.
- Ensure that error handling does not obscure the root cause of issues.
- Test error handling paths to confirm they work as intended.
- Create a user-friendly error reporting system to inform users of issues.
- Regularly review and update error handling strategies based on past experiences.
